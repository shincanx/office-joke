A one-line joke about office life: "per my last email", taken home and put in a will. The program writes the 89-character joke to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), deterministically, with no network access.

## Run it

```sh
python3 main.py
```
